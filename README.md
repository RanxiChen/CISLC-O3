# CISLC-O3

> **WIP — Work in Progress**

CISLC-O3 的目标是使用 SystemVerilog 实现一个 RISC-V 乱序执行处理器核心。

项目目前处于微架构设计与 RTL 框架重构阶段，正在沿指令运行路径逐步完善前端、解码、重命名、乱序调度、执行、访存、写回和顺序提交等模块。

当前实现尚不完整，不代表已经具备完整 ISA 支持、完整异常与分支恢复、可运行软件系统或经过充分验证的处理器功能。模块接口、流水线边界和内部实现仍可能持续调整。

## Repository Layout

- `rtl/`：处理器 RTL 实现。
- `doc/`：架构设计与当前实现状态文档。
- `sim/`：仿真环境及阶段性测试代码。
- `tb/`：测试平台与仿真顶层。
- `agent.md`：当前重构阶段的协作和修改约定。

当前开发内容以 `develop` 分支为准；在整体指令路径完成梳理前，测试与系统集成状态可能暂时落后于 RTL 重构进度。
