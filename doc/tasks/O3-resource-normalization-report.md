## 实现变化

| 模块 | 原来的膨胀原因 | 当前实现 |
|---|---|---|
| Decode Queue | 动态二维结构体读写未表达 lane 之间的 bank 互斥关系 | 固定 bank 的打包单写/单读 LUTRAM；原指针、容量与握手保持 |
| Rename→Dispatch Queue | 出队和恢复时搬动、压紧整个宽 uop | 数据固定槽位；只整理窄索引，分支掩码单独更新 |
| Fetch Buffer | 稀疏入队和 kill 空洞时压紧宽记录 | 固定数据槽和有序索引；保留任意空洞、FTQ 身份和 generation 行为 |
| Issue Queue | 调度、恢复、唤醒围绕搬动的宽 uop 建立大量选择器 | 固定数据槽，窄调度记录保存必要字段；选定索引后读完整 uop |
| FTQ | 宽结构体动态部分写产生反馈选择；只写一次的字段使用可更新寄存器 | 分配 PC/RAS 和慢预测 metadata 使用单写异步读 LUTRAM；可变状态按固定行更新 |
| Store Queue | 每字节完整地址比较，围绕队头旋转宽记录并串行选择 | 模 64 位地址差与字节掩码判断；物理项比较、平衡年龄选择；STA/HEU 先选索引再读记录 |
| INT/FP Writeback | 按端口和源串行更新年龄赢家 | 平衡年龄选择树，仅传递有效位、年龄、源索引；之后读取完整数据，保持相同年龄时的源顺序 |
| ROB | 宽 metadata 动态部分写；多路读写全部记录 | 分银行保存只在分配时写入的 metadata 和退休字段；异常、后继 PC、fflags、needs-D 等状态单独更新 |
| Load Queue | 回放选择围绕队头旋转完整记录；队列指针和计数使用无必要的 32 位状态 | 物理索引按环形年龄选择，再读宽记录；指针按容量定宽，计数保留足够符号位和原越界断言 |

ROB 的 RAM 不做整体复位；每行独立的 written 标志保证复位后读取仍为全零，包括无效公开输出。普通 flush 与误预测不会擅自清除原设计保留的数据。分配、完成、异常、D 位和后继 PC 同拍冲突的原优先级由逐周期对照检查。计数的定宽仍覆盖有效项数加分配数减释放数的完整范围，没有用无符号回绕掩盖非法占用。

没有删掉 PC、预测信息、异常 tval 或原始/展开指令字段；没有新增同步 RAM 读延迟或流水级。LUTRAM 与 BRAM 分开统计。

写回树的独立最差逻辑层数：INT 从 128 降到 51，FP 从 87 降到 25。INT LUT 增加 129，是本轮明确保留的深度与面积取舍；FP LUT 同时减少。最终树在一个组合过程内构造，消除了最初 aggregate array 的新增 UNOPTFLAT 告警，没有使用 lint 豁免。

无 `O3_SIM` 时 `decoded_uop_t` 实际为 485 位，已从编译常量 `UOP_BITS=0x1e5` 核实。原整机 Decode Queue FF 除以项数得到约 408，仅是剪枝后保留寄存器的粗估，不能当成结构体宽度。原始压缩指令与展开指令具有不同用途；移动 PC、预测或异常信息还涉及额外读口及生命周期，不能预先当作无代价删位。

## 判断与保留边界

本轮消除了已确认的宽队列搬移、动态部分写、逐字节全地址比较和串行宽记录选择。最终 footprint 用于下一阶段决策，不能预先把剩余 LUT 都归因于四发射本身，也不能把更大器件视为时序问题的解决。更大 FPGA 与缩配选择尚未做出。

既有 LiteX SD DMA 非 DDR 地址的 err/ack 限制未由本轮资源优化处理；功能回归 PASS 不构成所有错误路径无无限等待的证明。为给最后回归留出磁盘，仅清理已完成、确认无活动进程任务的 `.gch` 编译缓存；源码、生成头文件、二进制、日志和结果均保留，逐文件清单和删除结果在 `compiler-cache-prune/`。

## 网表复核与后续实现工作

读取最终 ROB 独立 OOC checkpoint 后，四路分配 PC 加指令长度共使用 32 个 CARRY8，即四个 64 位加法器。综合已经跨 64 个槽位共享这组计算，没有按每槽每 lane 复制，不应根据源码循环形态再做一次无依据改写。初次使用 `read_checkpoint` 查询未打开 OOC design，后改为 `open_checkpoint`，查询真实 exit=0；两次日志均保留在 `area/rob-cone-diagnostic/`。

这份报告完成本轮实现改写和验证，不能证明所有剩余成本都合理。长组合恢复/回放链仍需按最终逻辑锥继续定位；如需要增加流水级，必须先明确 kill、完成、退休及访存取消的周期约定，再实施和验证。后续仍按保留规格的实现优化推进，更换器件或缩减配置不在本轮决定范围内。
